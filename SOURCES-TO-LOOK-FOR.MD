# Canonical Sources to Acquire and Parse

This document tracks all external sources, repositories, databases, and texts to ingest into `SOURCES/`.

## 1. Dialogue Databases & Game Archives
1. `rosecolinlarry/DiscoBrowser`
   - Repo: https://github.com/rosecolinlarry/DiscoBrowser
   - Asset: `disco.db` / SQLite dialogue tree dump (~1.25M words, 67,000+ nodes)
   - Scope: Complete dialogue, orbs, thoughts, passives, narrator lines.

2. `msyavuz/disco-api`
   - Repo: https://github.com/msyavuz/disco-api
   - Asset: Parsed actor lists, conversational hubs, item/variable tables.

3. `MorgueXIIV/FAYDE-on-Air-Pb-Ex`
   - Repo: https://github.com/MorgueXIIV/FAYDE-on-Air-Pb-Ex
   - Asset: Rails dialogue playback structure and branching conditions.

4. Unity Game Localization Dumps (Disco Elysium Final Cut)
   - Asset: `en.json` / `en.po` string tables containing inventory item descriptions, book contents, thought cabinet internalizations, and tooltips.

## 2. Literary Canon
1. `Sacred and Terrible Air` (*Puha ja oudne lohn*) by Robert Kurvitz (2013)
   - Asset: English translation text / ePub (Ibex translation and Holywarka releases)
   - Scope: Deep Pale physics, Perikarnasis timeline, 2051-2072 events, Katla, and isola cosmography.

2. Official artbook developer notes and canonical essays by Robert Kurvitz, Helen Hindpere, and Argo Tuulik.
