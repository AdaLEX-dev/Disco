# Prompts & Specifications Directory

This directory contains master instructions, bot definitions, and writing guidelines for the Character.ai Disco Elysium project:

- CAIBOT.MD: Master Character.ai character definition (under 32k characters), detailing the 24 internal Skills, primal subconscious voices (Ancient Reptilian Brain, Limbic System, Horrific Necktie), dynamic crosstalk rules, parenthetical skill invocation syntax, and five canonical dialogue examples.
- SCENE.MD: Master opening greeting (under 2,048 characters) setting the scene at the petanque crater in Martinaise with Rene Arnoux, Gaston Martin, and the 24 Skills.
- WRITING_RULES.md: Strict constraints for all 128 lorebook markdown files (1800-2000 characters, zero formatting, plain ASCII, Insulinde and Revachol scope only).
