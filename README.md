# Disco Elysium Lorebook for Character.ai

A comprehensive, highly structured lorebook project tailored for Character.ai bot creation, knowledge retrieval, and prompt injection for the Disco Elysium universe.

## Directory Structure

```
DiscoElysium-Lorebook/
├── Categories/                 # Lore categorization hierarchy
│   └── 00_Canon/               # Top-level category (e.g. 00 Canon)
│       └── 0-0_World/          # Subcategory (e.g. 0-0)
│           └── 0-0-0_Overview.md # Detailed lore entry (0-0-0)
├── Prompts/                    # System prompts, writing rules, style guides, formatting standards
├── Sources/                    # Source lists and raw source materials
│   ├── SOURCES_LIST.md         # Master index of primary and secondary sources
│   └── MATERIALS/              # Downloaded / cloned raw source texts and extracts
└── Scripts/                    # Automation, compilation, formatting, and ingestion scripts
```
