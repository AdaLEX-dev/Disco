# Sources Directory Index

## 1. Dialogue Databases and In-Game Assets (Primary Extraction Targets)
- **DiscoBrowser / Fayde SQLite Database Dump**
  - Source: https://github.com/rosecolinlarry/DiscoBrowser
  - Raw SQLite dialogue tree database (`disco.db` / `dialogue.db`)
  - Word count: ~1.25 million words
  - Dialogue nodes: 67,000+ entries covering all branches, passive skill checks, thought cabinet observations, and narrator lines.
- **Disco API & Dialogue Tables**
  - Source: https://github.com/msyavuz/disco-api
  - Structured actors, conversations, and variables extracted from Final Cut.
- **Fayde Playback Repository**
  - Source: https://github.com/MorgueXIIV/FAYDE-on-Air-Pb-Ex
  - Complete conversational graphs and variable flags.
- **Disco Elysium Scribe Archive**
  - Source: https://disco-elysium-scribe.pages.dev
  - Script explorer with full variable timelines and skill check tables.

## 2. Literary and Supplemental Canon
- **Sacred and Terrible Air (Puha ja oudne lohn)** by Robert Kurvitz (2013)
  - English fan translations: Group Ibex translation (complete text and epub), Holywarka community version.
  - Estimated size: ~90,000 words.
  - Covers future timeline (Era of the Great Disappearance, year '51 to '72), isolas, deep Pale physics, Perikarnasis, and Katla.

## 3. Game Data Bundles
- Unity Dialogue Database asset bundle directly from Disco Elysium: The Final Cut.
- Localization string tables (`en.json` / `en.po`).
