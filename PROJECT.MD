# Disco Elysium Lorebook Project

Master documentation and specification for the Disco Elysium Character.ai Lorebook repository.

## Mission
Build a strictly canonical, comprehensive lore database formatted specifically for Character.ai bot creation, persona grounding, and context retrieval.

## Strict Format Constraints for Entry Files
Every entry markdown file inside subfolders must adhere to:

Title:
<Exact Title>

Text:
<Body text strictly between 1800 and 2000 characters spaces included>

Keywords:
<keyword 1>, <keyword 2> (minimum 2, maximum 8)

## Zero Formatting Rules
- Plain ASCII characters only.
- Absolutely no markdown asterisks, em dashes, en dashes, unnatural hyphens, tables, bullet points, or headers inside text.
- No outside non-canonical sources, fanfiction, or speculative hallucinations.
